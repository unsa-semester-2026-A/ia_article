# Problemas

- Sobre el Perú
  - Cámara en movimiento
  - Pocos datos de las regiones del Perú
- Lo que el Perú causa
  - que el modelo se aprenda el contexto (background) y no los autos
- Dataset
  - Autos solo en movimiento
  - Desvalance de clases
- En la literatura
  - Vacío en la literatura actual: Los trabajos previos abordan piezas aisladas como el error geométrico, el desbalance con técnicas crudas de copy-paste o el rastreo multiobjeto. Ninguno utiliza modelos generativos libres para corregir desde la raíz el sesgo de las instancias estáticas no etiquetadas en los datos de entrenamiento.
  - Ausencia de evaluaciones modernas: Ningún trabajo previo ha evaluado la arquitectura YOLO26 (Jocher2026) en este dominio específico.
  - Falta de herramientas de evaluación: No existe una implementación pública y validada de la métrica oficial exigida por el reto (Macro AP-rIoU@[0.50:0.80]).
  - Dependencia tecnológica y hardware limitado: Las soluciones requieren funcionar y ser validadas en hardware de bajo costo o accesible (como GPU T4). Además, existe el problema de las restricciones de uso que imponen las APIs propietarias para la generación de datasets, lo que obliga a depender de modelos de código abierto.

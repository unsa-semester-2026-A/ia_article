\section{Conclusions}
\label{sec:conclusions}

This research built and evaluated a train-only SAM copy-paste workflow for oriented vehicle detection in Peruvian traffic surveillance. The work included annotation auditing, YOLO-OBB conversion, clip-level validation preservation, mask-guided foreground extraction, synthetic image-label generation, YOLO26s-OBB training, homography-based motion filtering, and final Macro AP-rIoU scoring over six artifacts. The augmentation release contains 1,501 synthetic image-label pairs and 3,391 inserted vehicle instances, with no synthetic validation files.

The strongest final detector is Base 1, the raw-data baseline with minimal augmentation. It reaches 0.692 Macro AP-rIoU, 0.766 AP@0.50, 0.537 AP@0.80, and the best F1 at rIoU 0.50. Base 2 is almost tied in Macro AP-rIoU and is slightly better at AP@0.80, but it produces many more false positives. Improvement C is the best synthetic/LaMa variant and the fastest condition, with 98.9 FPS, yet it remains below Base 1 in the main metric. With these artifacts, the synthetic delta cannot be reported as an accuracy improvement over the raw baseline.

The importance of the result is that it prevents an overclaim. The generated images passed the intended validation checks, and the pipeline can be rerun, but final detection quality did not improve. For traffic applications, this distinction matters because downstream counting or trajectory analysis needs reliable rotated detections instead of visually plausible augmented samples or favorable training curves.

What remains from the work is a complete experimental chain for OBB-preserving augmentation. It shows how to keep validation data unchanged, how to package final predictions and diagnostics, and how to compare detector conditions with class-balanced rotated AP after motion filtering. It also identifies the next technical target: rare-class augmentation and visual-context control, especially for Motocicleta and other low-support classes.

The final observation is practical. Base 1 should be used as the main current detector, Base 2 should remain as the strict-localization comparator, and Improvement C should be kept for operational analysis because it is fast and reduces candidate load among the synthetic variants. Further work should not simply add more synthetic samples; it should test targeted per-class insertion, filter-on/filter-off scoring, matched-OBB visual audits, and repeated runs with uncertainty estimates.

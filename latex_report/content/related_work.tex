\section{Related Work}
\label{sec:related_work}

\textbf{Fernández-Rodríguez et al. — Automated detection of vehicles with anomalous trajectories in traffic surveillance videos (2023)~\cite{FernandezRodriguez2023}.}
The problem addressed by this work is how to automatically detect vehicles with anomalous trajectories using only traffic cameras, without relying on explicit ``motion'' labels. Its objective is to propose a model that compares velocity vectors of neighboring trajectories in order to flag those that deviate from the normal pattern. The main contribution is to demonstrate that a vehicle's motion state can be inferred by comparing trajectories over time, without requiring an explicit ``moving'' label. Methodologically, it combines per-frame detection, trajectory tracking, velocity-vector estimation, and comparison with spatially adjacent trajectories. As a result, the model successfully detects wrong-way vehicles and anomalous behaviors in real videos. However, its main deficiency is that it does not distinguish fully stationary (parked) vehicles from those circulating normally, which is precisely the core problem in our dataset, since train.csv does not annotate parked vehicles.

\textbf{Espinosa, Velastín \& Branch — Detection of motorcycles in urban traffic using video analysis: A review (2020)~\cite{Espinosa2020}.}
The problem motivating this review is that the detection and tracking of motorcycles — a vulnerable road user and a minority class in almost every traffic dataset — remains a poorly solved challenge. Its objective is to review the state of the art in motorcycle detection/tracking on CCTV and to consolidate available datasets and metrics. The contribution of this work is to explicitly map the problem of detecting a small, minority class (motorcycle/mototaxi), which is directly analogous to the imbalance we face in the MTC challenge. Methodologically, it consists of a literature review of deep learning algorithms applied to motorcycles, additionally introducing the Urban Motorbike Dataset (UMD). As a result, it identifies the best-performing detectors reported on UMD and outlines the field's current limitations. Nevertheless, its deficiency is that it neither proposes nor evaluates OBB architectures, nor does it address the filtering of stationary vehicles.

\textbf{Balamuralidhar, Tilon \& Nex — MultEYE: Monitoring system for real-time vehicle detection, tracking and speed estimation from UAV imagery on edge-computing platforms (2021)~\cite{Balamuralidhar2021}.}
The problem this work faces is that traffic monitoring systems must run in real time on low-compute embedded hardware, not only on server-grade GPUs. Its objective is to design a detection, tracking, and speed-estimation system optimized for embedded hardware onboard a UAV. The main contribution is to provide concrete proof that high accuracy can be maintained in real time under strict hardware constraints, validating the premise of our Layer 2 (accessible hardware). Its methodology is based on a multi-task detection architecture, with a segmentation head added to the backbone, executed on an Nvidia Xavier NX. The results show a 4.8\% improvement in mAP and a 91.4\% improvement in speed over the prior state of the art, reaching up to 29--33 FPS when embedded. As a deficiency, it focuses on aerial UAV video and does not discuss class imbalance or the discrimination of stationary vehicles.

\textbf{Alás, Cervera \& Sanfeliu — A Scalable Real-Time Multi-Camera Vehicle Tracking System for Urban Environments (2026)~\cite{Alas2026}.}
The central problem of this article is scaling real-time vehicle tracking systems across heterogeneous CCTV networks without relying on a dedicated GPU per camera. Its objective is to propose a modular, low-compute architecture for tracking across the edge-fog continuum. The contribution of this work is to provide evidence that a detection/tracking pipeline can sustain real-time performance on accessible hardware (CPU) at urban network scale, which is relevant for justifying the feasibility of our Layer 2. Methodologically, it combines lightweight detection, transformer-based appearance embeddings, and cross-camera association constrained by topology and travel time. As a result, it maintains over 80\% correct identity matches and 20--29 FPS per stream using only CPU across 27 real cameras. Its deficiency is that it targets cross-camera re-identification, a problem different from the per-frame detection required by the MTC challenge, and it does not address class imbalance or stationary vehicles.

\textbf{Gomaa et al. — Faster CNN-based vehicle detection and counting strategy for fixed camera scenes (2022)~\cite{Gomaa2022}.}
The problem addressed by this work is that automatic vehicle detection and counting in video remains computationally expensive for real-time use. Its objective is to propose a fast method for vehicle detection and counting on fixed cameras. The main contribution is to demonstrate that a fast detector combined with lightweight point tracking, without the need for a complex tracker, is sufficient to achieve accurate real-time counting, which is relevant to our Layer 3 (from detection to counting). Its methodology uses YOLOv2 for detection, together with motion feature-point analysis via K-means and a KLT tracker for counting. As a result, it improves from 1.24/0.19 FPS of prior methods to 18.7 FPS, while also improving counting accuracy. However, it does not address class imbalance, stationary-vehicle discrimination, or comparison with modern OBB architectures.

\textbf{Kumar et al. — Fusion of deep sort and Yolov5 for effective vehicle detection and tracking scheme in real-time traffic management sustainable system (2023)~\cite{Kumar2023}.}
The problem motivating this work is that existing detection/tracking methods fail under varying vehicle sizes, occlusions, and real-world scenarios. Its objective is to propose an effective real-time detection and tracking scheme for highway traffic management. The contribution of this article is to serve as a solid reference for the ``YOLO + Deep SORT'' pipeline, which we use as a benchmark for typical real-time vehicle detection and tracking performance. Methodologically, it combines YOLOv5 (140 FPS) for detection with Deep SORT, supported by a Kalman filter and the Hungarian algorithm for tracking. The results show 91.25\% precision, 93.52\% recall, and 92.18\% mAP on the BDD100K and PASCAL datasets. As a deficiency, it uses an older, non-OBB version of YOLO and does not consider class imbalance or the discrimination between moving and parked vehicles.

\subsection*{Summary of the gap}
None of the six reviewed works combines OBB detection, class-imbalance mitigation, and moving-vs-stationary vehicle discrimination within a single pipeline. Each addresses an isolated piece of the problem: motion-state inference from trajectories~\cite{FernandezRodriguez2023}, detection of a small, minority class~\cite{Espinosa2020}, deployment on low-cost embedded hardware~\cite{Balamuralidhar2021,Alas2026}, or real-time detection-and-tracking schemes used as baselines~\cite{Gomaa2022,Kumar2023}. This gap directly motivates our combined approach.

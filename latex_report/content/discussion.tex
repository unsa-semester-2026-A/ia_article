\subsection{Discussion}
\label{sec:discussion}

The updated artifacts change the interpretation from a pipeline-failure narrative to a sharper ablation result. Base 0 is useful as a zero-shot reference, but its 0.078 Macro AP-rIoU shows that the DOTA-pretrained detector and the partial Auto/Camion mapping are not enough for the nine-class Lima traffic taxonomy. Once the detector is trained on the task data, the score moves to the 0.65--0.69 range. The meaningful comparison is among the trained data conditions, not between trained and untrained inference.

Base 1 wins because it is the cleanest compromise between recall and false positives. Base 2 recovers slightly more true positives and reaches the best AP@0.80, but its false-positive count is more than twice that of Base 1 at rIoU 0.50. That cost is visible in precision and F1, and it explains why Base 2 does not become the best Macro AP-rIoU condition. In practical terms, stronger classical augmentation helped strict localization on some boxes but also made the detector more permissive.

The synthetic-data result is negative for the main hypothesis. Improvement B, which adds the SAM copy-paste delta to raw images, stays below Base 1 and Base 2. Improvement C, which combines LaMa pixels and the same copy-paste delta, is better than Improvement A and B in several operational diagnostics, but it still does not beat Base 1 in final AP. The safest statement is limited: the implemented synthetic delta changes the candidate distribution, especially false positives and throughput, but it does not provide a verified accuracy gain.

That finding fits a known caution in synthetic-data literature. Artificial or object-centric images can help when they add useful variation and preserve labels~\cite{Weber2021ArtificialImagesVehicleDetection,Mumuni2024,HuangW2025}; they can also fail when context, boundaries, or class sampling do not match the downstream task~\cite{Alimisis2025Advances,Benkedadra2024,ZhuH2025}. The present pipeline protects OBB labels more carefully than full-frame synthesis: it uses real foregrounds, SAM masks, train-only slots, and deterministic label writing. The final metrics show that these safeguards are necessary but not sufficient. For this dataset, the next augmentation revision should focus less on adding more pasted objects and more on where, at what scale, and for which classes they are inserted.

The class-level evidence points in that direction. Base 2 improves Combi, Minibus, Omnibus, and Camion, whereas Base 1 remains best for Auto, Microbus, Articulado, Mototaxi, and Motocicleta. Motocicleta is still the weakest trained class, with the best AP reaching only 0.292. Motorcycle and small-object studies report similar failures under clutter, low pixel support, and imbalance~\cite{Espinosa2020,Cheng2023SmallObjectSurvey,Nikouei2025SmallObjectSurvey}. A generic copy-paste quota is unlikely to solve that alone; the difficult classes need targeted sampling and visual-context checks.

The OBB metric also helps explain why the differences go beyond classification. Rotated detection penalizes center displacement, footprint scale, angle error, and polygon mismatch~\cite{Ding2022DOTA,Wang2025OBBSurvey,Zand2022OBB,Yang2021KLD}. Architectures such as Oriented R-CNN, ReDet, and S2ANet handle some of this through model design~\cite{Xie2021OrientedRCNN,Han2021ReDet,Han2022S2ANet}. Our experiment keeps the model family fixed and changes the data. The small AP@0.80 advantage of Base 2 suggests that data policy can affect rotated localization, but the false-positive cost limits the net benefit.

The motion filter should be read as part of the evaluation protocol, not as a post-hoc correction for a single model. It is applied uniformly and reflects the dataset emphasis on moving vehicles. Base 1 has the fewest removed predictions and the lowest post-filter false-positive count, which suggests that its detections better match the moving-traffic assumption. Improvement C is faster and cleaner than the other synthetic/LaMa variants, so it remains useful for operational analysis, but it does not alter the main detector ranking.

Training diagnostics require the same separation. Improvement B can show strong internal Ultralytics curves while remaining below Base 1 in the paper evaluator. The two measurements answer different questions: the training loop checks convergence under its validation setup, while the final evaluator uses the official class identifiers, coordinate correction, homography filter, and rIoU thresholds. For a scientific ablation, the latter is the evidence that supports or rejects the augmentation claim.

The practical decision from the current artifacts is straightforward. Base 1 should be treated as the main model for the final comparison. Base 2 should stay in the paper as the strict-threshold comparator because it has the best AP@0.80. Improvement C should stay as an operational variant because it reduces false positives among the augmentation conditions and is the fastest run. The copy-paste method remains valuable because it is traceable and repeatable, but the reported result must be negative with respect to final Macro AP-rIoU improvement.

\subsection{Discussion}
\label{sec:discussion}

The ablation results change the interpretation of the work from a purely methodological report to an incomplete but informative detector comparison. Base 1, the raw-data baseline with minimal online augmentation, is the strongest available final condition and the only one that produces non-zero true positives under the Macro AP-rIoU evaluator. This result makes Base 1 the current empirical reference for the project.

The zero score for Base 0 is expected to some extent because it is a zero-shot DOTA-weight baseline with only a partial class mapping. More important is the behavior of Base 2 and Improvement A. Both use trained checkpoints and emit many candidate detections, yet the final evaluator accepts no true positives. This pattern should not be simplified as "augmentation failed" without further audit. A zero AP with hundreds of thousands of false positives may reflect a checkpoint-selection problem, class-index mismatch, coordinate convention issue, or a real failure to align detections with the official oriented labels. The article therefore reports the result as an ablation finding and also identifies it as a required technical check before drawing a stronger causal conclusion.

For the proposed SAM copy-paste idea, the current evidence is promising but not complete. Improvement B has a coherent training trace: internal YOLO validation reaches mAP50 0.929 and mAP50-95 0.761, with high precision and recall by the final recorded epoch. However, those values come from the Ultralytics validation loop and do not include the paper's final motion filtering and Macro AP-rIoU scoring. The study cannot yet claim that the SAM copy-paste delta improves the final metric. That conclusion requires the pending Improvement B final evaluator package and the pending Improvement C artifact.

The class-wise Base 1 profile also clarifies where augmentation should matter most. Motocicleta and Articulado remain the weakest classes, while Microbus and Omnibus perform substantially better than their raw frequencies alone would suggest. This indicates that class imbalance is only one part of the problem. Vehicle size, orientation stability, label geometry, and visual ambiguity also affect Macro AP-rIoU. Future synthetic additions should therefore be evaluated not only by how many minority samples they add, but by whether they improve the classes and geometries that currently limit the macro score.

The shift away from IC-Light remains justified. The available final augmentation set uses segmentation-assisted copy-paste because it preserves a direct relationship between real foreground pixels and explicit OBB labels. IC-Light was useful as visual exploration, but the implemented production data do not rely on full-frame relighting or image hallucination. Given the current ablation evidence, the strongest defensible claim is not that synthetic data already improves final AP, but that the project now has a controlled augmentation mechanism and an evaluation protocol capable of detecting whether it does.

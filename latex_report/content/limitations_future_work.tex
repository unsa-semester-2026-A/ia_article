\subsection{Limitations and Future Work}
\label{sec:limitations_future_work}

The main limitation is that the ablation is still missing the final Macro AP-rIoU package for Improvement B. Improvement B has training metrics and saved weights, but no final evaluator ZIP in the uploaded artifact set. Consequently, the current paper can compare Base 0, Base 1, Base 2, Improvement A, and Improvement C at the final-evaluator level, while Improvement B must remain a training-diagnostic result.

A second limitation is artifact heterogeneity. Base 1 is available as a consolidated final-metrics JSON, while Base 0, Base 2, Improvement A, and Improvement C are available as full final evaluator ZIP packages with manifests and hardware logs. The metric fields and validation size are compatible, but the packaging difference reduces traceability for Base 1. Future runs should export every condition through the same final evaluator script and artifact schema.

The zero true-positive results for Base 2, Improvement A, and Improvement C also require follow-up. Because these checkpoints produce many predictions, the failure may come from class remapping, OBB coordinate conventions, checkpoint selection, confidence handling, or model behavior after stronger augmentation, LaMa-corrected pixels, and synthetic additions. A targeted audit should inspect a small set of predictions visually, verify class-index conversion, compare raw and filtered predictions, and rerun final scoring on a small controlled subset before interpreting these conditions as definitive model failures.

Finally, the study still lacks repeated runs and statistical uncertainty estimates. All F1 conditions use a fixed seed and a shared validation split, which supports controlled comparison but does not measure training variance. Future work should export Improvement B through the final evaluator, repeat the strongest conditions under multiple seeds, and report confidence intervals or bootstrap variability for Macro AP-rIoU and class-wise AP. Manual review of a small static-slot subset would also strengthen confidence that pasted vehicles are inserted into semantically valid locations.

\subsection{Limitations and Future Work}
\label{sec:limitations_future_work}

The final comparison uses one validation split and one trained artifact per condition. That is enough to compare the uploaded artifacts, but it does not measure training variance. The next version should repeat the five trained conditions with multiple seeds and report confidence intervals or bootstrap intervals for Macro AP-rIoU, AP@0.50, AP@0.80, and class-wise AP.

The reported final results use the homography-based motion filter as the official evaluation setting. The choice is consistent across all conditions and matches the dataset goal of scoring moving vehicles, but it hides the exact before/after effect of filtering. Future work should report paired filter-on and filter-off metrics for the same artifacts, including true positives removed by the filter, false positives removed by the filter, and AP variation after filtering.

The paper does not yet include a visual audit tied directly to final matching. The artifacts contain raw predictions, filtered predictions, homographies, class-level metrics, and threshold-level metrics, but no frame-by-frame overlays of matched and unmatched OBBs are shown. Those overlays would help separate class confusion, OBB vertex-order issues, angle error, coordinate conversion, static-object filtering, and genuine visual ambiguity.

The synthetic delta is also fixed. It contains 1,501 synthetic image-label pairs and 3,391 inserted instances, but the experiment does not separately vary foreground quality, placement context, per-class quota, object scale, or source reuse. Since Motocicleta remains weak and the synthetic variants do not beat Base 1, future augmentation should test targeted class-balanced sampling and stricter visual-context validation instead of only increasing the number of pasted objects.

The evaluation protocol should also be extended. The current rIoU thresholds stop at 0.80, while COCO-style protocols commonly extend to 0.95 for horizontal boxes. A future OBB protocol could report AP@0.50, AP@0.75, AP@0.80, Macro AP-rIoU over 0.50--0.80 for comparability with the current comparison, and an additional stricter range if the annotation precision supports it. Efficiency metrics should also be expanded with model size, parameter count, FLOPs, preprocessing time, homography time, and postprocessing time.

Future versions should compare the data-centric approach with model-level strategies, such as class-balanced losses, rare-class oversampling, small-object resolution changes, OBB-specific loss tuning, confidence calibration, and architectures designed for rotated detection. The long-term goal is to show measurable gains in class-aware rotated localization under an unchanged validation protocol, not just to generate more synthetic examples.

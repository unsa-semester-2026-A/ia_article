\subsection{Limitations and Future Work}
\label{sec:limitations_future_work}

The main limitation is that the ablation is not yet complete. Improvement B has training metrics and saved weights, but its final Macro AP-rIoU package is still missing. Improvement C has not yet been uploaded. Consequently, the current paper can compare Base 0, Base 1, Base 2, and Improvement A at the final-evaluator level, but it cannot make a final claim about the SAM copy-paste intervention.

A second limitation is artifact heterogeneity. Base 1 is available as a consolidated final-metrics JSON, while Base 0, Base 2, and Improvement A are available as full final evaluator ZIP packages with manifests and hardware logs. The metric fields and validation size are compatible, but the packaging difference reduces traceability for Base 1. Future runs should export every condition through the same final evaluator script and artifact schema.

The zero true-positive results for Base 2 and Improvement A also require follow-up. Because these checkpoints produce many predictions, the failure may come from class remapping, OBB coordinate conventions, checkpoint selection, confidence handling, or model behavior after stronger augmentation and LaMa-corrected pixels. A targeted audit should inspect a small set of predictions visually, verify class-index conversion, compare raw and filtered predictions, and rerun final scoring on a small controlled subset before interpreting these conditions as definitive model failures.

Finally, the study still lacks repeated runs and statistical uncertainty estimates. All F1 conditions use a fixed seed and a shared validation split, which supports controlled comparison but does not measure training variance. Future work should complete Improvement B and Improvement C final evaluations, repeat the strongest conditions under multiple seeds, and report confidence intervals or bootstrap variability for Macro AP-rIoU and class-wise AP. Manual review of a small static-slot subset would also strengthen confidence that pasted vehicles are inserted into semantically valid locations.

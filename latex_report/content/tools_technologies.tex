\subsubsection{Tools and Technologies}
\label{sec:tools_technologies}

The experimental routines are organized in the repository package for experiments. The environment targets Python 3.12 and separates local and cloud dependencies through package metadata and lock files. The software stack covers annotation parsing, tabular processing, image geometry, model training, notebook execution, and automated validation.

Training and inference are based on the Ultralytics YOLO26s-OBB implementation~\cite{Jocher2026}. The runner exports a YOLO dataset YAML with nine zero-indexed classes: auto, combi, microbus, minibus, omnibus, articulado, camion, mototaxi, and motocicleta. PyTorch provides the tensor and automatic-differentiation backend used by the Ultralytics runtime~\cite{Paszke2019PyTorch}; GPU execution is carried out in CUDA-enabled cloud notebooks.

OpenCV supports the geometric operations required by the augmentation and evaluation stages, including polygon handling, homographies, image warping, connected components, alpha blending, and image serialization~\cite{Bradski2000OpenCV}. SAM is called through the Ultralytics adapter with the SAM-B checkpoint~\cite{Kirillov2023SAM}. Notebook execution is used for GPU-backed experimentation and is consistent with prior notebook-centered research workflows~\cite{Garavagno2022ColabNAS,Zhao2021NaaVRE}. Resource evidence is recorded with a lightweight monitor that samples process statistics and NVIDIA SMI output.

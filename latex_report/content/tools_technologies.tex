\subsubsection{Tools and Technologies}
\label{sec:tools_technologies}

The experimental code is organized as a Python package under \texttt{experiments/}. The package metadata pins Python to the 3.12 series, NumPy to version 1.26.4, setuptools to version 70.0.0, wheel to version 0.43.0, Ultralytics to version 8.4.103 in the cloud and local optional dependency groups, and LAP to version 0.5.13. Pytest 8.1.1, Pyright 1.1.350, and Ruff 0.15.14 are pinned for development validation. OpenCV, pandas, PyYAML, scikit-learn, tqdm, Torch, Torchvision, Albumentations, and Google API client libraries are declared by package metadata but are not all pinned to exact versions.

Model training and inference use the Ultralytics implementation of YOLO26s-OBB~\cite{Jocher2026}. The training runner writes a standard YOLO dataset YAML with nine zero-indexed class names: auto, combi, microbus, minibus, omnibus, articulado, camion, mototaxi, and motocicleta. It uses PyTorch through the Ultralytics runtime; PyTorch is cited as the underlying tensor and automatic differentiation framework~\cite{Paszke2019PyTorch}. Cloud notebook environments provide the CUDA-compatible PyTorch builds used in GPU execution.

The augmentation code uses OpenCV for polygon geometry, homographies, alpha compositing, connected components, image warping, and JPEG/PNG serialization. SAM is accessed through the Ultralytics adapter with the SAM-B checkpoint in the production notebook. Cloud notebooks are used as execution environments, consistent with notebook-based research workflows and GPU-backed experimentation~\cite{Garavagno2022ColabNAS,Zhao2021NaaVRE}. The code also records resource and GPU evidence through a lightweight monitor based on process statistics and NVIDIA SMI samples.

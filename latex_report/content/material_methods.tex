\subsubsection{Data Access Statement}
\label{sec:data_access}

The dataset is registered and distributed through the \href{https://www.kaggle.com/competitions/mtc-smart-challenge-ia-para-la-movilidad-del-peru/data}{competition page on Kaggle}, hosted by Peru's Ministry of Transportation and Communications (MTC)~\cite{MTC2026SmartChallenge}. Access requires acceptance of the competition rules and Kaggle's terms of service. For development convenience, a mirror of the dataset and trained weights are also stored in a \href{https://drive.google.com/drive/u/0/folders/1FVBV0QnS9BLqLNiHSN6v-gjGFMOOgOXc}{Google Drive folder}. The raw data files---\texttt{train.zip}, \texttt{test.zip}, \texttt{train.csv}, and \texttt{sample\_submission.csv}---are not redistributed as part of this work. The code developed for data preprocessing, format conversion, and model training is released under the GPLv3 license, independently of the dataset distribution terms. The repository location and version identifier are provided in the Code Availability statement.

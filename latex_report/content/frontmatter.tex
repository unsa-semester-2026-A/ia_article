\begin{abstract}
Traffic surveillance systems require reliable vehicle detection under changing viewpoints, illumination, occlusion, scale, and class imbalance. This work presents a segmentation-assisted synthetic augmentation workflow for oriented vehicle detection in Peruvian traffic imagery. The method characterizes the dataset, converts annotations to YOLO oriented bounding boxes, extracts real vehicle instances with Segment Anything Model masks, inserts them into train-only safe slots, and preserves validation data unchanged. The resulting augmentation set contains 1,501 synthetic image-label pairs and 3,391 inserted instances. The evaluation protocol implements Macro AP-rIoU over nine classes and seven rotated-IoU thresholds with a homography-based motion filter. The main contribution is a validation-preserving augmentation methodology that increases minority-class training evidence while maintaining explicit geometric correspondence between generated pixels and oriented labels.
\end{abstract}

\begin{abstract}
Camera-based traffic surveillance can support urban mobility analysis, but reliable vehicle detection remains difficult in dense urban scenes from Lima because viewpoint, illumination, occlusion, scale, orientation, and class imbalance affect the visual evidence available to a detector. This paper presents \textit{Segmentation-Assisted Synthetic Augmentation for Oriented Vehicle Detection in Peruvian Traffic Surveillance}, a validation-preserving workflow for increasing minority-class training evidence in an oriented bounding box setting. The method audits the traffic dataset, converts parametric annotations to YOLO-OBB labels, extracts real vehicle instances with Segment Anything Model masks, places them into train-only safe slots, and evaluates predictions with Macro AP-rIoU over nine classes and seven rotated-IoU thresholds using a homography-based motion filter. The implemented augmentation release contains 1,501 synthetic image-label pairs and 3,391 inserted instances, with no synthetic validation files. The main contribution is a reproducible, segmentation-assisted copy-paste methodology that preserves explicit correspondence between generated pixels and oriented labels while avoiding unverified full-frame generative synthesis.
\end{abstract}
